# 참고 자료

2026-09-10 공개 준비 과정에서 유사한 대학 상담 프로젝트의 소개 방식을 검토했다. 아래 저장소는 README 구성 참고 자료이며, 이번 공개 준비에서 이들의 코드를 복사하거나 수강메이트의 성능 근거로 사용하지 않았다.

| 자료 | 참고한 구성 | 이 저장소에 적용한 방식 |
|---|---|---|
| [Course RAG — Adaptive RAG Chatbot for University Course Selection](https://github.com/xqs-xqs/adaptive-rag-course/blob/main/README.md) | 기능·질문 처리 구조·빠른 시작·평가를 구분하는 흐름 | 질문 유형별 처리와 지표의 측정 범위를 별도 설명 |
| [RAG-Based University Assistant Chatbot](https://github.com/SohaibBazaz/RAG-Based-University-Assistant-Chatbot) | 프로젝트 목적·데이터 준비·사용 흐름·실행 방법 | 수강 선택의 구체적인 불편함과 과목 비교 시나리오 제시 |
| [University RAG Chatbot](https://github.com/TheWerbinator/university-chatbot/blob/main/README.md) | 설계 문서 연결, 실행 가능한 예시, 평가 명령 제공 | 설계 결정·시연·검증 절차를 README에서 바로 연결 |

각 프로젝트의 구현과 발표 수치는 해당 작성자의 설명이다. 수강메이트의 결과는 [자체 평가 보고서](evaluation.md)와 저장된 집계를 기준으로 한다.
