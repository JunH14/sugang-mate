# 실제 사용자 검증 계획

상태: **아직 실시하지 않음**. 이 문서는 다음 검증의 절차이며 성과가 아닙니다.

## 대상과 과제

대상 학과 학생 3~5명이 과목 2개 비교, 특정 요일의 전공선택 찾기, 평가방식 확인, 후속 질문, 자료에 없는 질문을 수행합니다. 실제 데이터의 공개 범위를 먼저 확인하고 질문 기록은 동의를 받은 범위에서 익명화합니다.

## 기록

| 익명 참가자 | 과제 | 성공 여부 | 소요 시간 | 출처 확인 여부 | 불편 사항 |
|---|---|---|---|---|---|

직접 강의계획서를 찾는 경우와 앱을 이용하는 경우에 난도가 비슷한 과제를 배정하고 순서를 바꿉니다. 소규모 관찰 결과를 일반 사용자 전체의 효과로 확대하지 않습니다.

## 후속 조치

관찰된 오류는 재현 질문과 기대 동작을 기록해 회귀 테스트에 추가합니다. 실제 사용 시간 단축률·만족도 수치는 이 절차를 수행한 후에만 포트폴리오에 기재합니다.
